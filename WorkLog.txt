2. 발견된 예외 사항 및 우회법 (Known Issues & Workarounds)
--------------------------------------------------------------------------------
[이슈 1] Python 설치 시 UAC 권한 상승 실패 (WinGet Exit Code 50)
- 원인: 비대화형 셸에서 WiX 번들 py.exe 런처가 C:\Windows에 설치되려 하며 권한 상승(UAC) 실패
- 우회법: 'Include_launcher=0 InstallAllUsers=0' 옵션을 전달하여 사용자 디렉터리에 비관리자 모드로 완벽 설치

[이슈 2] transformers 5.x의 인위적 PyTorch >= 2.6 버전 제한
- 원인: pip 기본 설치 시 transformers 5.24가 설치되어 PyTorch 2.5.1을 비활성화하는 문제 발생
- 우회법: 'transformers>=4.40.0,<5.0.0' (v4.57.6)으로 버전을 고정하여 PyTorch 2.5.1과 완벽 연동

[이슈 3] CVE-2025-32434 보안 경고로 인한 torch.load 제한
- 원인: transformers 최신 버전에서 .bin 가중치 로드 시 PyTorch 2.6 미만 버전 차단
- 우회법: 'use_safetensors=True' 플래그를 적용하여 laion/clap-htsat-unfused의 safetensors 가중치를 직접 로드해 차단 우회

[이슈 4] LotsOfSounds 스트리밍 엔드포인트 응답 형식
- 원인: /stream 엔드포인트 호출 시 원본 오디오 스트림이 아닌 서명된 S3 URL이 담긴 JSON을 반환하여 librosa 파싱 헤더 에러 발생
- 우회법: /stream 엔드포인트의 JSON에서 actual stream_url을 2차 추출하여 실제 mp3 바이트를 다운로드하도록 파이프라인 수정
